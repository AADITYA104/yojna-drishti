# ADR-0015: Theme selection (superseded)

- **Status:** SUPERSEDED by ADR-0017
- **Date:** 2026-10-31

## Context
The early dashboard references used dark surfaces and the initial design discussion had not yet selected a single theme.

## Problem
Choose between light, dark or page-specific themes.

## Options considered
(a) Light only; (b) dark only; (c) different theme by screen; (d) allow a user-controlled theme switch.

## Provisional decision
The original proposal supported both light and dark pending owner review. This was not an approved final design and was superseded when the owner supplied the Final Master Dashboard UI direction.

## Consequences
Do not treat the former dark palette as current. Follow ADR-0017 and the current design-system.md.
