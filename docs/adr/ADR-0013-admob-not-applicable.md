# ADR-0013: AdMob NOT APPLICABLE

- **Status:** ACCEPTED
- **Date:** 2026-10-31

## Context
Web dashboard; no native app approved; Part 0 mandates this classification.

## Problem
Advertising stance.

## Options considered
(a) none; (b) ads in web.

## Selected decision
(a).

## Reasoning
Simplest option that satisfies the requirements and Part 0/Part 1 constraints; see Advantages.

## Advantages
Neutral government platform, no third-party tracking.

## Disadvantages
No revenue.

## Consequences
Revisit only with a native app ADR.
