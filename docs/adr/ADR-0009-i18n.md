# ADR-0009: next-intl with one catalog per language

- **Status:** PROPOSED
- **Date:** 2026-10-31

## Context
Gujarati and English are first-class.

## Problem
Choose i18n.

## Options considered
(a) next-intl; (b) custom context; (c) i18next.

## Selected decision
(a).

## Reasoning
Simplest option that satisfies the requirements and Part 0/Part 1 constraints; see Advantages.

## Advantages
Server component support, typed keys.

## Disadvantages
Library dependency.

## Consequences
Missing-key test in CI.
