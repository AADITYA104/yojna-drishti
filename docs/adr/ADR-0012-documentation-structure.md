# ADR-0012: Documentation structure and naming follow Part 0

- **Status:** ACCEPTED
- **Date:** 2026-10-31

## Context
Part 0 and Part 1 name files differently.

## Problem
Avoid duplicate or conflicting docs.

## Options considered
(a) Part 0 names and folders; (b) Part 1 names; (c) both copies.

## Selected decision
(a) with alias map.

## Reasoning
Simplest option that satisfies the requirements and Part 0/Part 1 constraints; see Advantages.

## Advantages
One file per topic.

## Disadvantages
Aliases need the map.

## Consequences
DOCUMENTATION_MAP.md kept current.
