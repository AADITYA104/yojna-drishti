# AdMob Specification

**Status: NOT APPLICABLE.**

Justification: YOJANA DRISHTI Version 1 is a web dashboard. AdMob is a mobile SDK for native apps. No native mobile app is approved. Advertising inside public government scheme analytics is not allowed by default (it would compromise neutrality and add third-party tracking).

If a native app is approved later: create a new ADR, a privacy review, consent design (DPDP), placement policy excluding scheme statistics screens, and update this document, privacy.md and BRAIN.md.

Control: NFR-ADV-01 test checks the production build contains no advertising scripts.
