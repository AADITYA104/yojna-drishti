# Glossary

| Term | Meaning |
|---|---|
| ADR | Architecture Decision Record |
| Aggregate | Count or sum over many people; no individual identifiable |
| ARCHIVED | Data mode for historical/superseded data |
| Beneficiary enrolment | One person enrolled in one scheme; people are not de-duplicated across schemes |
| DEMO | Synthetic data mode, always badged |
| DPDP | Digital Personal Data Protection Act 2023 and Rules 2025 (India) |
| FY | Financial year, April to March, text YYYY-YY |
| GR | Government Resolution |
| Gram Panchayat (GP) | Elected rural local body; may cover several revenue villages |
| LGD | Local Government Directory; source of unit codes |
| MVT | Mapbox Vector Tile format |
| Revenue village | Land-revenue unit, the village level in this product |
| Sanctioned | Amount approved for beneficiaries (distinct from allocated and disbursed) |
| Suppression | Hiding small counts to protect privacy |
| Taluka | Sub-district |
| VERIFIED | Published data with recorded official or authorised provenance |
| Yojana | Scheme (Gujarati) |
| Drishti | Vision |
